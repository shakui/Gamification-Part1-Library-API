# Геймификация — часть 1: библиотека классов и Web API

- `Gamification.Core` — библиотека классов: игроки, опыт (XP), уровни, достижения
- `Gamification.Api` — ASP.NET Core Web API со Swagger
- `Gamification.Core.Tests` — модульные тесты

## Запуск

```
dotnet run --project Gamification.Api
```

Swagger: http://localhost:5257/swagger

Тесты: `dotnet test`
